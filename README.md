# Crusoe Cloud Go Client

This repository hosts the official Crusoe Cloud golang API client. The client is entirely autogenerated from our API's OpenAPI spec.

## Authentication

Two credential types are supported: a static access key/secret key pair, and OAuth2 service-account client credentials.

```go
// Static key.
client := auth.NewAuthenticatedAPIClient(accessKey, secretKey)

// Service account.
client, err := auth.NewServiceAccountAPIClient(ctx, clientID, clientSecret, tokenURL, audience)
```

To auto-detect which credential type to use, resolved in this order - explicit options, then
environment variables, then `~/.crusoe/config` - use `NewDefaultAPIClient` instead:

```go
client, err := auth.NewDefaultAPIClient(ctx)
```

Environment variables: `CRUSOE_ACCESS_KEY_ID` / `CRUSOE_SECRET_KEY` for a static key,
`CRUSOE_SERVICE_ACCOUNT_CLIENT_ID` / `CRUSOE_SERVICE_ACCOUNT_CLIENT_SECRET` (optionally with
`CRUSOE_SERVICE_ACCOUNT_TOKEN_URL` / `CRUSOE_SERVICE_ACCOUNT_AUDIENCE`) for a service account.
Configuring both at once is an error. `auth.WithProfile(name)` selects a named profile from the
config file; `auth.WithConfigPath(path)` points at a config file in a non-default location, e.g. a
mounted Kubernetes Secret.
